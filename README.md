# nptelpsychquiz
The website can be accessed [here](https://d23e510rj4xkj6.cloudfront.net/NPTEL-PsychCourse).

This is a simple static website built using HTML, CSS and JS hosted on AWS S3 delivered through AWS CloudFront.

The purpose of this website is to quiz students based on the questions of assignments provided in the NPTEL Course of 'Psychology of Stress, Health and Well-Being'.

All question data has been scraped from the website associated with the NPTEL Course.

This website does not claim ownership of any data extracted from there. The original course has been linked below.
